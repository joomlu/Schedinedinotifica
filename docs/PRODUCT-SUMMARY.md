# Product Summary

Sistema de "schedine di notifica" para alojamientos:

- Gestion de clientes en todas las fases: richiesta (solicitud), ospite (alojado), componente/acompanante.
- Registro de check-in y check-out con datos completos (sin asignacion de habitaciones).
- Calculo y cobro de la tassa di soggiorno, generando el archivo requerido para la Comune.
- Envio diario de las notificaciones obligatorias a la Questura (con sus codigos).
- Envio mensual a ISTAT con los codigos ISTAT correspondientes.
